# Gasto Claro - Control Financiero Inteligente

## Descripción
Aplicación de control de gastos personal con IA para el contexto argentino.

## Stack Tecnológico
- Frontend: React + TypeScript + Vite
- Backend: Node.js + Express + PostgreSQL
- IA: TensorFlow.js + Google Vision API
